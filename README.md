# 写真アプリ (photo-apps)

写真・動画まわりの小さな Web アプリをまとめたリポジトリです。

**入口:** https://mizuho-works.github.io/photo-apps/

| パス | アプリ | 内容 |
| --- | --- | --- |
| `best-shot-picker/` | ベストショット整理 | 連写した写真・動画から「いらないかも」を自動で選ぶ |
| `koma/` | コマ選び | 動画からアルバム用の一枚を切り出す（撮影日時つき JPEG） |
| `hizuke/` | 日付そろえ | 切り出した写真を元の動画、加工した写真を元写真と照合し、撮影日時を入れる |
| `bounce/` | バウンスメーカー | 動画の一部を「行って戻る」ループ動画にする |

`main` に push すると GitHub Actions で GitHub Pages にデプロイされます。

### 日付そろえ：加工後の写真の日付を復元

`hizuke/` の「照合する元データ」で「元の写真 → 文字入れ・加工した写真」を選び、元写真と加工後の写真を別々に追加します。元のJPEGのEXIF撮影日時を読み取り、画像の特徴で照合します。日時がない場合は手入力できます。タイムゾーンがないEXIFは端末のタイムゾーンで扱います。

結果の元写真・日時を確認し、必要なら候補を手動で変更してZIP保存してください。似た連写や大きく加工した写真は誤照合する場合があります。JPEGは画像の向きが通常なら画像データを再圧縮せず日時を付け替え、それ以外はJPEGに変換します。画像内の文字は変更しません。元ファイルは上書きしません。

日時処理の確認: `node hizuke/tests/dates.cjs`
