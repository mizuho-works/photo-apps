ショートカットの作り方

⌂

ベストショット整理の削除候補を、写真アプリの「削除候補」アルバムに自動で入れるためのショートカットです。最初に一度だけ作れば、あとはボタンを押すだけで使えます。

アクションは、ショートカット編集画面の下にある検索欄に名前を入れると見つかります。iOSのバージョンによって表示が少し違うことがあるので、英語名も添えています。

1. アルバムを用意する

  1. 写真アプリ →「アルバム」→ 左上の＋ →「新規アルバム」
  2. 名前を 削除候補 にして保存（写真は選ばなくてOK）

2. ショートカットを作る

  1. 「ショートカット」アプリ → 右上の＋
  2. 上の名前を 削除候補に追加 にする
    ※ 一字でも違うとアプリから呼び出せません

3. アクションを順番に追加する

  1. テキストを分割 Split Text
    青い「テキスト」をタップ →「ショートカットの入力」を選ぶ。区切りは「改行」。
  2. 各項目を繰り返す Repeat with Each
    対象が「分割されたテキスト」になっていればOK。

ここから下の3〜6は「繰り返す」と「繰り返しの終了」の間に入れます。

  1. テキストを分割 Split Text
    入力は「繰り返し項目」。区切りを「カスタム」にして ,（半角カンマ）を入れる。
  2. リストから項目を取得 Get Item from List
    「最初の項目」のまま。入力が 3 の「分割されたテキスト」になっていることを確認。
  3. リストから項目を取得 Get Item from List
    「最後の項目」に変える。入力の部分を長押し →「変数を選択」→ 3 の「分割されたテキスト」をタップ。
  4. 写真を検索 Find Photos
    はじめから入っている条件があれば ⊖ で消す →「フィルタを追加」→ 項目を「作成日」、条件を「範囲内」（英語表示では is between）にする。
    1つ目の日付欄に 4 の「項目」、2つ目に 5 の「項目」を入れる（欄をタップ →「変数を選択」）。
    「制限」がオンならオフにする。

ここから下は「繰り返しの終了」の下に入れます。

  1. アルバムに追加 Add to Album
    入力を「繰り返しの結果」、アルバムを「削除候補」にする。
  2. 数を取得 Count
    入力を「繰り返しの結果」にする。
  3. 通知を表示 Show Notification
    本文を「［数］件を削除候補に入れました」にする（［数］は 8 の結果を変数で入れる）。

できあがりはこんな形です：

ショートカットの入力 を 改行 で分割
各項目を繰り返す
    繰り返し項目 を「,」で分割
    最初の項目 を取得
    最後の項目 を取得
    作成日 が［最初］〜［最後］の写真を検索
繰り返しの終了
繰り返しの結果 を「削除候補」アルバムに追加
繰り返しの結果 の数を取得
通知「○件を削除候補に入れました」

右上の「完了」で保存します。

4. 使ってみる

  1. ベストショット整理の「削除の手順」画面で「削除候補」アルバムに入れるをタップ
  2. 「ショートカットを開きますか？」→「開く」。写真へのアクセスを聞かれたら「許可」
  3. 通知の件数が、ボタンに出ていた件数と同じくらいか確認
  4. 写真アプリで「削除候補」アルバムを開いて、中身をざっと確認

連写のように同じ秒に何枚も撮った写真は、秒単位でしか探せないため、「残す」写真が一緒に入ることがあります。アプリの画面に⚠で表示されるので、その写真は選択から外してから消してください。

うまくいかないとき

  • 「ショートカットが見つかりません」… 名前が 削除候補に追加 と完全に同じか確認。
  • 0件になる… 6 の「写真を検索」で、はじめから入っていた条件（アルバムなど）が残っていないか確認。
  • 「ショートカットの入力」が選べない… ショートカットの編集画面下の ⓘ →「共有シートに表示」をオンにすると選べるようになります。
  • 関係ない写真がたくさん入る… アルバムから選んで「アルバムから取り除く」で外せます。写真自体は消えません。
