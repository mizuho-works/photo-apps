# motto — 写真コラージュ

スマホ向けの写真コラージュ。HTML・CSS・JavaScriptだけで動作し、写真は端末内で処理します。

公開URL: https://mizuho-works.github.io/photo-apps/motto/

## 使い方

1. 「写真を追加」またはプレビューの空の枠をタップして写真を選択（最大12枚）。
2. 下の「フレーム」を開き、丸い数字で枚数とフレームを選択。もう一度押すか「×」で閉じます。
3. プレビューの写真をタップして個別に調整。ドラッグで移動、ピンチまたはスライダーで25〜400%の拡大縮小。「完了」で戻ります。
4. 右上の保存アイコンでPNG画像として保存。対応スマホでは共有メニューから「画像を保存」を選べます。

## 編集機能

- 外枠余白：外側の余白・写真の間隔・角の丸み
- フレーム：均等グリッド、大きな1枚を中心にした組み合わせ
- カスタム／作成：縦の段数と横の列数を指定。縦4 × 横3は12枚
- 背景：8色のプリセットと任意の色
- 比率：4:3、3:4、1:1、4:5、3:2、9:16
- 保存設定：長辺1600pxまたは2400pxのPNG
- 写真ごとにリセット・変更・削除
- 元に戻す・やり直す：写真や調整、フレーム、色など直近30状態まで保持
- 通常時はプレビューと4つのメニューだけを表示。「簡単配置」はありません
- アイコンはLucide v0.468.0のSVGを同梱（icons/LICENSE.txt参照）

枚数を減らして隠れた写真は、枚数を戻すと再び表示されます。未配置の枠は保存画像では背景色になります。写真を縮小したり移動したりしてできた空白にも背景色を使います。ページを再読み込みすると写真と編集内容はリセットされます。

HEICなどブラウザで読み込めない画像はJPEG・PNGに変換してください。端末への保存方法はブラウザによって異なります。

## ローカル起動

```sh
python3 -m http.server 3000
```

http://localhost:3000 を開きます。依存ライブラリ・ビルド・外部フォントは不要です。
